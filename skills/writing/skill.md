# Technical Writing & Documentation Standards

## Principles
1. **Audience-Centric Tone**: Adapt prose for the intended audience (executive overview vs. in-depth developer handbook).
2. **Scannability**: Utilize headings, callouts, tables, bullet points, and code snippets.
3. **Clarity Over Jargon**: Prefer direct, active-voice sentences over passive or unnecessarily complex phrasing.
4. **Actionable Outcomes**: Every guide or proposal should conclude with concrete next steps, checklists, or implementation details.
