# Data Analysis & Computational Workflow

## Workflow
1. **Understand Data Shape**: Identify schema, row count, null values, and numeric distributions.
2. **Execute Calculations**: Use the `calculator` or `code_runner` tool for deterministic calculations, avoid guessing or mental arithmetic on complex numbers.
3. **Format Results**: Present aggregated metrics in structured Markdown tables with explicit units (USD, ms, percentages).
4. **Insights & Trends**: Highlight anomalies, key trends, outliers, and recommendations based on the findings.
