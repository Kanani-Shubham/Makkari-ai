# Modern Frontend & UI Engineering

Follow modern aesthetic standards and engineering best practices for web interfaces:

## Design Guidelines
- **Palette**: Use curated, harmonious color palettes with high-contrast text and sleek dark mode support.
- **Typography**: Structure clean typographic hierarchies with proportional letter-spacing and line-heights.
- **Accessibility**: Ensure ARIA attributes, semantic HTML elements, keyboard navigation, and visible focus states.
- **Micro-Interactions**: Use subtle CSS transitions (150ms-250ms ease-out) for hover, active, and focus states.
- **Mobile First**: Design responsive flex/grid layouts that adapt gracefully across mobile, tablet, and widescreen viewports.
- **Framework Neutrality**: When the user requests a single HTML file or vanilla HTML/CSS/JS, generate self-contained CSS inside `<style>` and JavaScript inside `<script>`. Do not introduce React, Next.js, or Tailwind unless explicitly requested.
