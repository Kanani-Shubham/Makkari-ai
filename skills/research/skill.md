# Deep Research & Web Investigation Workflow

## Investigation Standards
1. **Autonomous Tool Usage**: Use `web_search` to query live web sources and `fetch_url` to inspect primary source documentation.
2. **Triangulate Facts**: Cross-reference key claims across multiple reputable publications or documentation sites.
3. **Structured Synthesis**: Present information with structured summaries, pros/cons comparison tables, and direct source attribution.
4. **Distinguish Knowledge Cutoff**: Clarify when information requires live verification versus established domain concepts.
